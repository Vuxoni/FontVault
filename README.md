# FontVault
Modern temporary font manager for Windows 11 built with WinUI 3

FontVault lets you temporarily load fonts into Windows without permamently installing them, making it ideal for designers or anyone who frequently works with large font collections.

<img width="443" height="306" alt="image" src="https://github.com/user-attachments/assets/4a0974a1-41d0-4d98-a969-1d72c85e6c86" />


# Features
- Load `.ttf` and `.otf` fonts from any folder
- Temporary font loading
- Unload individual fonts
- Unload all temporary fonts with a single click
- Automatic cleanup when FontVault closes
- Duplicate font detection

# Built With
- C#
- .NET 8
- WinUI 3
